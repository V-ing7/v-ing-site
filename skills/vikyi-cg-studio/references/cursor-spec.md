# 冰蓝玻璃指针（Cursor Glass）规格

参考 Bibata Modern Ice 的观感，但**用矢量重绘**，不引用原主题的 `.cur` / `.ani` 文件，避免授权问题。

## 画布与尺寸

| 参数 | 值 |
| --- | --- |
| 画布 | 3840×2160 / 30fps / 120 帧（4 秒） |
| 指针高度 | 画布宽 × `0.07` = 269px（1080p 下 134px） |
| 箭头 viewBox | `84 × 132`，路径 `M2.4 2.4 L2.4 118 L28.6 92.4 L44.2 130.6 L63.4 122.6 L47.6 84.6 L82.4 84.6 Z` |
| 缩放单位 | `u = 高度 / 132`，所有描边、阴影、涟漪宽度都乘 `u` |

## 造型

- 冰蓝渐变：`#FFFFFF` → `#E2F2FE`（38%）→ `#B2DCF8`（78%）→ `#8FC8EE`（100%），整体 0.95~0.99 不透明
- 深色描边 `rgba(8,18,32,0.94)`，`5.2u`，`linejoin/cap = round`
- 内描边 `rgba(255,255,255,0.55)`，`1.6u`（玻璃的第二层线）
- 左缘细白高光：`3.4u`，从白色渐隐到透明——**只允许这一条沿边缘的细线**，不是横穿画面的光带
- 投影 `drop-shadow(0 10u 22u rgba(0,0,0,0.38))`，透明画布上必须靠投影把指针从画面里"抬"起来
- 不透明部分 alpha 约 248，画布其余 alpha 0

## 动效

| 段落 | 帧 | 内容 |
| --- | --- | --- |
| 入场 | f0–20 | `spring(damping 190, mass 0.85, stiffness 105)`，从 (0.68w, 0.68h) 滑到 (0.53w, 0.47h)，f0–7 淡入 |
| 单击 | f36–46 | 指针 `scale 1 → 0.9 → 1`（压下回弹） |
| 涟漪 1 | f38–78 | 半径 `0 → 0.55h`，白色描边，透明度 `0 → 0.55 → 0` |
| 涟漪 2 | f46–92 | 同上，冰蓝色描边，透明度 `0 → 0.34 → 0`，错开 8 帧 |
| 停留 | f92–120 | 完全静止 |

不要加：扫光、顶部高光带、背后柔光、指针抖动、拖影。

## 变体思路（用户若要）

- 双击：第二圈涟漪在 f64 再起一次，间隔 4 帧
- 拖拽：f60 后指针按下不放（scale 0.92），并加 3 个残影（间隔 3 帧、透明度递减）
- 多指针：复制 composition，`defaultProps` 传不同起点即可
