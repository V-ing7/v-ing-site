# 液态玻璃样式参数（v3 基线，Vikyi 专用）

对照 `assets/src/TitleBarGlass.jsx` 阅读。改任何一条，都要把新值写回素材库记录的 `style` 字段。

## 已移除的东西（不要加回来）

| 曾用过 | 移除原因 |
| --- | --- |
| 顶部镜面高光带（32% 高度白色渐变） | Vikyi 明确「取消高光」，顶部那条亮白边太抢眼 |
| 斜向扫光（18° 白带，f24–86 横扫） | Vikyi 明确「不要扫光」，横穿画面的光带干扰实拍 |
| 背后柔光 halo（椭圆径向白雾） | 叠在实拍上发灰，且让 PNG 序列体积翻倍 |

如果用户又要，先确认清楚再动，并同步改 `style`。

## 画布与本体

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 画布 | 1920×1080 | 与站点规格一致，可直接叠 1080p 时间线 |
| fps | 30 | 常规剪辑帧率 |
| 帧数 | 120（4 秒） | 入场 0.8s + 停留，够片头也够段落标题 |
| 本体 | 1180×232，圆角 44 | 占画面上部中区，不抢镜 |
| 字体 | PingFang SC / Microsoft YaHei | 中文在 macOS / Windows 都稳 |

## 玻璃层（自上而下叠）

1. **glass**
   `linear-gradient(180deg, rgba(255,255,255,0.13) 0%, rgba(26,26,32,0.34) 16%, rgba(14,14,20,0.46) 52%, rgba(6,6,10,0.58) 100%)`
   顶部一点白让边缘「接入」画面，往下渐深，保证白字在亮画面上也有对比。
2. **scrim**
   `linear-gradient(180deg, rgba(0,0,0,0) 30%, rgba(0,0,0,0.14) 100%)`
3. **底部内发光**
   2px 白线，`left/right` 各内缩 8%，`rgba(255,255,255,0.55)` 向两端渐隐，opacity 0.7。
4. **颗粒**
   `feTurbulence fractalNoise baseFrequency 0.85 numOctaves 3 seed 7`，opacity 0.055，`mix-blend-mode: overlay`。只铺条内，不铺整画布。
5. **描边**
   `1px solid rgba(255,255,255,0.58)` + `inset 0 1px 0 rgba(255,255,255,0.85)`、`inset 0 -1px 0 rgba(255,255,255,0.22)`、`inset 0 0 42px rgba(255,255,255,0.10)`、`0 18px 60px rgba(0,0,0,0.28)`。

描边 + 底部内发光是这条素材唯一的「光」，不要再叠任何高光。

## 文字与动效

| 元素 | 参数 |
| --- | --- |
| eyebrow | 21px，字距 9，大写，`rgba(255,255,255,0.82)`，阴影 `0 1px 12px rgba(0,0,0,0.45)`，f10–24 上浮 10→0 |
| 标题 | 74px / 600，`#FFFFFF`，`lineHeight 1.16`，字距 14→3（f14–40，easeOutCubic），阴影 `0 2px 26px rgba(0,0,0,0.50), 0 0 1px rgba(255,255,255,0.9), 0 1px 2px rgba(0,0,0,0.35)` |
| 分隔线 | 1px，宽 0→168px（f22–48，easeInOutCubic），两端渐隐到 0 |
| 胶囊标签 | 右下 34/28，`rgba(255,255,255,0.16)` 底 + `0.42` 描边，16px 字距 3，f38–54 从 0.88 弹到 1 |
| 入场 | `spring(damping 200, mass 0.9, stiffness 110)`，scale 0.965→1，y 30→0，整体 f0–8 淡入 |
| 文字透明度 | eyebrow f10–24、标题 f14–32、分隔线 f22–48、胶囊 f38–54 |

没有扫光之后，中段（f48–120）画面完全静止，靠文字留在画面上保持存在感。

## 两套 tone

- `dark`（默认）：上面这套烟熏玻璃 + 白字。任何亮度画面都成立。
- `light`：`linear-gradient(180deg, rgba(255,255,255,0.38), rgba(255,255,255,0.17) 30%, rgba(255,255,255,0.09) 62%, rgba(255,255,255,0.16))`。只适合深色画面；亮画面上白字会糊。

## 已知取舍

- 颗粒对 PNG 压缩极不友好：带颗粒单帧约 580KB，去掉约 230KB。要交 PNG 序列时先问要不要关。
- 4 秒 1080p RGBA 序列约 70MB，不要进仓库。
- 透明画布上 `backdrop-filter` 无效，玻璃只能靠多层半透明模拟——这条不要试图「优化」成 backdrop-filter。
